📊 Super Store Sales Analytics Dashboard
1. Project Title / Headline
Super Store Sales DashboardAn interactive Power BI dashboard built to analyze retail sales, profit, and quantity performance across Region, Category, Segment, and Time.2. Short Description / Purpose
The Super Store Dashboard provides a 360° view of retail operations.It helps track total Sales, Profit, and Quantity, and breaks them down by Category, Sub-Category, Segment, Region, and Ship-Mode.This tool is intended for retail managers and business analysts to identify top-performing products, regions, and sales trends for 2019-2020.3. Tech Stack
📊 Power BI Desktop - Data visualization and dashboard🔄 Power Query - Data cleaning and transformation🧮 DAX - KPIs: Total Sales = SUM(Sales), Total Profit = SUM(Profit)🔗 Data Modeling - Star schema with Date, Region, Category dimensions📁 File Format - .pbix for report4. Data Source
Superstore Dataset - Sample retail data with Order Date, Region, State, Category, Sub-Category, Segment, Sales, Profit, Quantity5.
